# ローカル素材フォルダ

ここにロゴ・画像・動画を置くと、「ロゴ・動画」タブの一覧へ反映されます。タブを開いている間は3秒ごとに更新し、「更新」でも読み直せます。画像のサムネイルまたは動画名を押すと読み込みます。

- 画像：PNG、JPEG、WebP、GIF、SVG
- 動画：MP4、M4V、WebM（MOVは非対応。再生できるコーデックはブラウザに依存します）
- 1ファイル200MB（200 × 1024 × 1024バイト）まで。サブフォルダとシンボリックリンクは対象外です。
- ファイル名に `..`、区切り文字、制御文字は使用できません。
- 素材ファイルはGitの追跡対象外です。外部へアップロードしません。
- `npm run dev` と `npm run preview` から、このフォルダの現在の内容を読みます。
- 「素材フォルダを開く」はこの場所をFinderなどで開きます。
- フォルダから選んだ素材の名前・表示設定を次回も復元します。ファイルが無ければ案内を表示し、ほかの動作を続けます。
- 「画像を選ぶ」「動画を選ぶ」はその場限りで、このフォルダへコピーしません。
- Gitに残すのはこのREADMEと `.gitkeep` だけです。必要な素材は別途バックアップしてください。

読み込みは同じ端末の `localhost`、`127.0.0.1`、`[::1]` からだけ利用できます。
